## PDF2FB2 1.1.0 (debug, иллюстрации и OCR offline)

- [Скачать APK — 47 MB](https://raw.githubusercontent.com/yury1978/PDF2FB2-downloads/v1.1.0-android-debug/PDF2FB2-1.1.0-debug.apk)
- [Скачать ZIP — 31 MB](https://raw.githubusercontent.com/yury1978/PDF2FB2-downloads/v1.1.0-android-debug/PDF2FB2-1.1.0-Android.zip)
- [SHA-256](https://raw.githubusercontent.com/yury1978/PDF2FB2-downloads/v1.1.0-android-debug/SHA256SUMS-1.1.0.txt)

Android 8.0/API 26 или новее; `pl.pdf2fb2`, versionCode 12.
Иллюстрации JPEG/PNG между абзацами, обложки и растеризация векторных схем.
Из сканов выделяются только уверенно отделённые фотографии, а текст проходит OCR.
Все изображения внутри одного FB2: binary Base64, проверка XSD, дедупликация.
Предпросмотр показывает миниатюры; текст можно редактировать. Есть отмена и предупреждения.

«Zachowaj ilustracje» включено по умолчанию, качество «Wysoka».
«Standardowa» даёт меньший файл; «Oryginalna, jeśli możliwa» сохраняет исходный простой JPEG,
а сложные изображения могут быть ограничены памятью/размером. Проверьте важные детали схем.
OCR pol/rus/eng с моделями внутри APK, полностью offline. Интернет, Termux и Python не нужны.
Иконка версии 1.0 сохранена.

Сертификат тот же, что у выданной 1.0.0. Откройте новый APK и выберите «Обновить»;
не удаляйте старую установку. Перед обновлением сохраните открытую книгу:
незаписанная правка находится только в памяти процесса. Обновление и сохранение контрольного приватного файла проверены
на эмуляторе. Другой сертификат препятствует обновлению; сначала экспортируйте книги.
Это техническая сборка **debug**, не производственная подпись и не Google Play.
Версия 1.1 ещё не проверена на физическом телефоне; пользователь подтвердил 1.0.0.

Проверено на эмуляторе Android 8.0 x86_64: **26/26 тестов**, без пропусков.
37 тестов Python и 19 тестов Java также прошли; Android Lint — 0 ошибок, 10 предупреждений.
23 итоговых FB2 проверены по локальному XSD, MIME, данным изображений и ссылкам;
ещё 8 результатов текстовых/OCR регрессий прошли XSD.
Книга 40 страниц: 80 иллюстраций, 41 уникальный ресурс.
Результаты действительно открыты в MuPDF и KOReader. API35 и физический телефон 1.1 не проверены.

Ограничения: сложные колонки, таблицы, сканы и схемы могут требовать ручной проверки.
OCR иногда путает Ё/Е; автоматическая замена букв не применяется. Кандидат обложки определяется
по первой крупной иллюстрации. Есть явные ограничения памяти и размера; пропуски/масштабирование
показываются предупреждениями. Длинную конвертацию выполняйте с открытым приложением;
редактор не восстанавливается после остановки процесса.

APK SHA-256: `264802675b0d79554649e4ba3834ca670f52bc45bc98a2f29b85412c5cac51aa`.
